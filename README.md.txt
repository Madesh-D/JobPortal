# JobPortal - Job Application Management System

A full-stack Job Portal application built using Java, Spring Boot, MySQL, React and Bootstrap.

## Features

### User Features
- User Registration
- User Login
- BCrypt Password Encryption
- Search Jobs
- Filter Jobs by Location
- View Job Details
- Apply for Jobs
- Prevent Duplicate Applications
- View My Applications
- Track Application Status
- Logout

### Admin Features
- Admin Login
- Add Jobs
- Edit Jobs
- Delete Jobs
- View All Applications
- Update Application Status

## Technology Stack

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- REST API
- MySQL
- BCrypt
- Maven

### Frontend
- React
- JavaScript
- Bootstrap
- HTML
- CSS
- Vite
